## Approved software

Approved apps install without a ticket from **[Software Center]** (Windows) or **[Self Service]** (macOS).

## New software

If an app isn't in the catalog:

1. Open a **Software request** in **[service desk portal]**.
2. Include the app name, link, what you'll use it for and whether it costs money.
3. IT checks it for security and licensing, then installs it or suggests an approved alternative.

Don't install unapproved software or browser extensions on company devices.
